## 我现在能独立解释什么

- List 适合保存有顺序、允许重复的数据；Set 适合保证元素唯一；Map 适合通过唯一 key 查询 value。
- Map 中重复 `put` 相同 key 会更新 value，而不是新增键值对。
- `put` 返回被替换的旧值，`remove` 返回被删除的值；键不存在时通常返回 `null`。
- `containsKey` 能区分“键不存在”和“键存在但 value 为 null”。
- `Integer` 是 `int` 的包装类型，可以用于泛型并且可以保存 `null`。
- `entrySet()` 返回由键值对组成的 Set；`keySet()` 返回键的 Set；`values()` 返回 Collection，因为 value 可以重复。
- 词频统计需要遍历原始数组；遍历刚创建的空 Map 不会执行任何统计。
- 联系人添加时必须先通过 Set 的手机号唯一性检查，再同步加入 List 和 Map，否则三个集合会不一致。
