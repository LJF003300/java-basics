## 学习规则

- 每天开始时阅读对应任务，不提前查看别人实现。
- 每个程序至少手动验证一个正常输入和一个边界输入。
- 从 Day 14 开始，业务逻辑必须通过测试验收。
- 禁止提交 `target/`、IDE配置、数据库密码或JWT密钥。
